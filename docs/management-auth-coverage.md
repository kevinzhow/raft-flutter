## Authority and credentials

Every management request is fenced by account/workspace generation, principal, server, role, and request ticket. A local authority change immediately clears private state and closes forms and credential dialogs. A backend 401/403 also clears previously readable payloads on reads or mutations and closes rejected management forms. An operation that completes under an obsolete scope cannot open a new private dialog. These checks include same-generation role downgrade and delayed provider history.

One-time secrets, webhook signing keys, private sharing codes, password and OAuth handoff values remain transient. Secret widgets start masked. No credential or provider reply is written to workspace cache, test screenshots, logs, or build definitions. Credential form values preserve intentional whitespace.

## Channel conversion boundary

The pinned flag migration enables configurable evaluation but defaults `channel_to_joint_conversion_v0` to false. Native channel settings fail closed on false, unknown, or failed evaluation, and evaluate again before each conversion command. The Linux 01:49:11 full-run checkpoint verified the live default-OFF control remains hidden. The mounted source supports ordinary/private channels converting to joint channels. It does not expose completed joint → ordinary conversion; cancellation compensates eligible work before audience cutover, and completed joint channels retain the existing disconnect workflow.

`POST /channels/:id/convert-to-joint` sends `observeProgress: true` and a fresh UUID `commandId`. An admitted command is distinct from the durable worker job. The UI polls mounted channel/job projections, never treats a completed command or a transport failure as completed conversion, and retains uncertain pending observations only in the current client's memory across widget remounts. Retry and cancel use the mounted job routes; `canCancel` and cutover facts remain server-authoritative. Active upload recovery lists actual session filenames and cancels through the mounted upload-session endpoint, without exposing session identifiers or replacing the uploader transport.

The exported SDK `channelConversionBlocksSending` follows the shared source projection: a pending command or pending/running/failed job blocks sending, except a failed job whose rollback is restored. A pending retry/cancel still overrides an older restored job. Malformed canonical projections fail closed. HTTP error details are immutable, narrowly allowlisted conversion/archive receipts; stale authorized HTTP failures cannot expose their private payload after a session/workspace change. UI mutation and polling fences additionally reject same-generation role/channel authority changes and old replies after cancellation.

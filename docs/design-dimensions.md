## Verification and drift contract

`validate_dimension_contract.py --source-root <pin checkout>` validates full source-file SHA plus exact cited excerpts. It fails changed source; it does not silently re-extract guessed values. `--native-root <R> --check-native` additionally validates native frozen-file SHA and anchors. It does not prove numeric arithmetic, resolved CSS cascade, mapping completeness or visual parity. `build_dimension_contract.py` creates reviewed receipts; regeneration requires review of changed rules. Dynamic CSS/viewport expressions stay typed rules, not arbitrary constants. A future root-owned tool integration can require this validator before geometry/capture tests.

Each visual acceptance case must record theme, mounted variant, viewport width/height, DPR, density, safe insets, actual font settling, visual/layout/hit rectangles, callback/keyboard behavior and screenshot source hash. Layout wrapping and min-width constraints belong to shared composition, not per-page nudges.

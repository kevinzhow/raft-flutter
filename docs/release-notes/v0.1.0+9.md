- feature: Settings > Storage lets you choose the cache limit (256 MB to 5 GB), and the cache is ready much sooner after launch.
- improvement: In the phone image viewer, a tap hides the top bar, caption, thumbnails and video controls together and the picture fills the space; a playing video hides its controls after 3 seconds, and double-tap zooms to 2x.
- improvement: Pinch-to-zoom in the image viewer starts as soon as the second finger lands instead of turning the page.
- improvement: Selecting message text highlights and copies everything, including inline code, code blocks, links and mentions, with a line break between blocks; on desktop a drag can start beside a short message.
- improvement: On phones, selected message text shows Copy and Select all.
- improvement: The server list refreshes when the app returns to the foreground, so servers joined or left elsewhere appear without a restart.
- fix: Web addresses right after Chinese text or punctuation become links, and the link stops at Chinese punctuation.

- feature: New default look that matches the Raft web app; Elegant and Brutal stay available as optional appearances in Settings > Appearance.
- feature: Cloud agents: create an agent that runs in the cloud, see its status, retry, stop the current turn, view 7-day usage and cost, move a local agent to the cloud, connect GitHub, and adopt the official identity (on servers that offer it).
- feature: RaftBench: the page with tasks and cost, conversation insights and legacy rules, for server admins.
- feature: Agents are archived instead of deleted, and archived agents can be listed and read; the agent profile shows an Activity overview, runtime error banner and subagent badges.
- feature: Create Agent remembers your last computer, runtime and model, suggests a name and picks a random avatar; model provider connections can be switched on and off.
- feature: Joint channels: invites in the bell, connected servers, direct connect and Disconnect; the channel header shows links and a muted bell, tabs can be reordered, and Slack channels can be paired.
- feature: Forwarding and sharing: a join banner before forwarding to a channel you are not in, a warning for joint channels, a share preview with copy image and Share to X.
- feature: Attachments: direct uploads for large files with resume, a banner for unfinished uploads, summaries on document and diff cards, drag to reorder pending files, and comment anchors on text lines, table rows and video times.
- feature: Activity: unread thread replies roll up onto their channel in the sidebar, Mark All as Read, a conversation list with pinned items first, and an "Earliest / Next unread thread" pill in channels.
- feature: Navigation: message links into another workspace open the local copy, the desktop rail remembers where you were in each section, the window title follows the open conversation, search can continue past the first results, and desktop has a "Find a conversation" box.
- improvement: Message rows follow the web app: Markdown links and references are recognised more reliably, video cards can retry, forwarded messages show their source and note, and message actions include Saved, Quote, Copy and Follow.
- improvement: Resizable profile panel and file tree, and reduced motion is respected in more places.
- fix: Fewer repeated requests while scrolling past documents and when returning to the app, and other servers' unread counts no longer refresh while the app is in the background.
- fix: A memory leak when switching servers or sessions is fixed.

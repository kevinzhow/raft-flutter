- feature!: Tasks follow the web's task v2: a task has its own conversation, one message can carry several tasks, the task title and fields can be edited, and handoffs and returns show their reason.
- feature!: Activity follows the web: one Filter (All, Unread, Mentions, Pinned, Saved, Artifacts), rows grouped by day, and "N in progress · M unread" at the top. On phones, swipe a row to mark it read or done, with Undo; tapping Activity again jumps to the next unread. Activity's own search, sort and grouping are removed, as on the web.
- feature!: On phones the bottom bar is Home, Activity, Tasks, Search and your server; Members, Computers and Settings open from the server tab. The bottom-bar customisation is removed.
- feature: Artifacts open in the app with their versions and files, appear as cards in chat, and an attachment can be saved as an Artifact.
- feature: Agent pages follow the web: status with Retry, runtime errors, stopping the current turn, the Activity tab, creating agents and external agents, connections and the runtime form.
- feature: Computers: a new rack view, Add Computer, card states, bulk restart, drag to move, and per-runtime sign-in, usage and limit resets.
- feature: Two-step verification, recovery codes and "Verify it's you" before sensitive actions.
- feature: Plan & Billing shows your plan, usage and payment method. Upgrading, adding seats and managing billing open the web page. Free servers show the 30-day history notice and the file-size and upload limits.
- feature: The message menu adds Forward, Mark as unread and, on phones, Select text, in the web's order.
- feature: iOS: paste copied photos and files into the composer; Android can paste files too.
- improvement: The look follows the Raft design system (raft-ui 0.95.3) across forms, menus, dialogs, lists, cards and messages. Raft is now the only look: Elegant and Brutal are retired.
- improvement: Android uses the Raft typeface (Space Grotesk) for Latin text, with the system font for Chinese.
- fix: Copy link now copies at once; before, it could leave the clipboard unchanged. Links to earlier messages show their preview without reloading.
- fix: Attachments open from Saved, Search and other conversations instead of doing nothing.
- fix: The message toolbar no longer stays on top of a profile panel opened over the chat.
- fix: Attachment previews on desktop no longer show a dark band under the header.
- fix: A panel opened beside a list shows its divider again, rack avatars are no longer stretched, and the Members list can be narrowed.
- fix: A rare crash in the accessibility layer no longer shows the error page.

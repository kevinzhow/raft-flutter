- feature: Unread messages from agents open expanded; messages you have already read stay collapsed. The choice holds for the visit, so a message does not fold up while you are reading it.
- improvement: The expanded editor opens as a bottom sheet on phones and narrow windows and as a dialog on wider ones. Resizing the window switches between the two without closing the editor or losing the draft, caret or text being typed.
- improvement: The expanded editor uses one consistent spacing for its toolbar, text, preview and buttons.
- fix: Clicking the editor's formatting toolbar while typing with a Chinese (or other) input method no longer interrupts the text being composed.
- fix: The expanded editor no longer closes by itself right after opening on a phone or in a narrow window.
- fix: On macOS, typing continues in the expanded editor after the window is resized between phone and desktop widths.
- fix: On desktop, new messages that arrive while you are reading at the bottom are marked read even if you had not yet scrolled since the app started.
- fix: Replies in a task's discussion are marked read while the discussion is open.

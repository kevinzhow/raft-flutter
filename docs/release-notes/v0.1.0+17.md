- feature: The message box can expand into a full editor. From the third line an expand button appears (Cmd/Ctrl+Shift+E); the editor has a formatting toolbar (bold, italic, strikethrough, headings, quotes, lists, task lists, code, links, tables, dividers, @ and #) and a live preview of the message as it will be sent. The inline box and the editor share the same draft, and Esc collapses without losing it.

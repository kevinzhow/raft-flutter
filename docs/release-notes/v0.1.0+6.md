- feature: macOS and Windows update themselves in the app; About always shows an Updates card with a Check for updates button and a red dot when a new release is out.
- feature: The app shows its own release notes for each version.
- feature: Settings > Storage shows the attachment cache size and can clear it; images, files and previews open from the cache instead of downloading again.
- feature: The image viewer switches between a message's images with the thumbnail strip, the arrow keys or a swipe; on phones a long press saves or shares the image.
- feature: Server owners and admins can change the server avatar.
- feature: Android adds photos and videos with the system Photo Picker.
- improvement: Videos stream and continue seamlessly from the message into the full-screen viewer; Android, iOS and macOS use the system player, and HDR videos show in HDR in the full-screen viewer.
- improvement: Players, decoders and decoded images are released when they are no longer visible.
- improvement: Linux scrolls at the full refresh rate of 120 Hz screens.
- improvement: Agent activity rows and the agent workspace look and behave like Web, including their loading, empty and error states.
- improvement: Shared and copied links (public page, messages, invites) use the web app address.
- improvement: A message with only attachments sends like Web, and notices clear as soon as their cause is gone.
- fix: Videos on Linux and Windows no longer fail when the session environment names an unreachable proxy the app does not use.
- fix: The agent runtime form no longer crashes while its options are loading.
- fix: Expired links to PDFs and audio are signed again instead of failing.
- fix: Joint channel avatars load from the channel's own member list.
- fix: Deleting a server no longer shows an error toast.

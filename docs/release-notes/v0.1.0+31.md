- fix: Opening a direct message from an agent's profile on a phone or folded foldable no longer bounces back to the channel when you tap the composer. Folding, unfolding, rotating or resizing the window keeps the pages you have open, and Back no longer lands on a blank page.
- fix: Agents that just joined show their avatar in the channel member list and in a message's "which agents" view right away, with a default pixel avatar when they have none.
- fix: The Built-in Pi runtime form works on servers with saved provider connections: pick a saved provider or set one up directly, and edit a saved provider from the form.
- feature: The notification bell shows when an agent hits its usage limit, with the computer, the affected agents and when it resets; the red dot counts only what you have not seen.
- feature: Wide windows can put a side thread in focus mode from the thread menu.
- feature: Agent migration has its own section on the agent profile, with progress, cancel and retry in place.
- feature: Apps can enable agent access tokens, and reviewers can approve pending app permission updates.
- improvement: Message rows, the thread panel header, the forward dialog, the login page, the agent profile, computer details, the sidebar, the public server page and Slack settings now match the Raft web app (v1.21.12) more closely, including Lucide 1.55 icons and updated Chinese text.
- improvement: Long messages fold behind "Show more" like the web app; unread agent messages still start expanded. Links in documents, forwarded messages and attachment comments open, and `obsidian://` links ask before opening.
- improvement: Runtime model lists are current (Claude Haiku 5.5, Codex GPT-6.1 Sol as the Codex default), model fields are searchable, and the deprecated Copilot CLI is no longer offered for new agents.
- improvement: Adding a computer on macOS and Linux is a single command; computer cards explain failed or unanswered upgrades and show "Upgrading…" while a computer restarts for its upgrade.

- fix: On macOS, Command-W closes the open preview or page first and the window last, and the Close and Settings menu items work. Closing the window keeps Raft running; quit from the menu or Dock.
- fix: On Windows, closing the window keeps Raft running in the tray. Quitting from the tray, installing an update or signing out of Windows now finishes saving local data first.
- fix: On every desktop platform, the local message cache is closed cleanly when Raft quits.
- fix: Messages you send in quick succession now appear in the order the server received them.
- fix: Opening a channel from search no longer loses your search, so going back returns to the results.
- fix: History no longer goes missing after you start returning to the latest messages and then scroll back.
- fix: Desktop notifications now appear when Raft opens or switches servers while its window is in the background, and phones keep notifying while the app starts up.
- fix: The Activity header in the Brutal theme grows with larger text sizes instead of clipping.

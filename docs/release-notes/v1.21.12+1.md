- improvement: The app version now follows the Raft server version it is aligned with (this release: 1.21.12); updates from 0.1.0 install normally.
- feature: Sign-in: a social sign-in whose email already has an account offers to connect to it; social sign-in asks you to accept the terms explicitly; your device time zone is reported to the server.
- feature: Your own member profile lets you change your picture and description; feedback screenshots, sent or not yet sent, open full size.
- feature: Computers: detect and rescan runtimes, read release notes, and copy a connect-only command; agent model names come from the server's catalog.
- feature: Tasks: starting an unassigned task claims it, the Board/List choice is remembered, older tasks show a Legacy badge, and the card shows its status first with "View in thread" in the task bar.
- feature: Apps: an app installation setup page, a hint when Slack @-mentions can't reach some members, and app events for everyone in the channel.
- feature: Public servers: an "Allow search engines" switch and a public globe on the server and its channels; public pages show attachments, mentions, reactions, reply previews and translation, and use one column on phones.
- feature: Help > Join Chinese Community opens the community QR page.
- improvement: Read state follows the Raft web app more closely: a failed read is retried, a conversation you just read is not marked unread again by older data, "Mark as Unread" shows the server's count, and followed threads stay in sync.
- improvement: Scrolling long conversations no longer runs history maintenance for every conversation, which reduces memory work during scrolling.

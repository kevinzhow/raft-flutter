- fix: In a thread opened from Activity, tapping "Back to bottom" no longer drops the channel name from the header or disables the composer.
- fix: The unread count next to Activity in the sidebar is a small badge again instead of a tall bar; the member-type and Archived labels no longer stretch either.
- fix: Android: after notifications were denied for good, Enable opens the system notification settings; a blocked message channel shows as off instead of "enabled"; a saved server on your local network asks for local network access instead of loading forever on Android 17.
- fix: Video playback stops downloading as soon as the player goes away, instead of fetching the rest of the file in the background.
- fix: Works with newer Raft servers: the removed agent token setting is gone, and server-targeted announcements arrive.
- feature: Agent migration has its own section on the agent profile, with progress, cancel and retry in place; agents on a deprecated runtime show a warning, and a failed start says why.
- feature: Agents on a hosted runtime have a Model card to pick their model.
- feature: Announcements show their label, picture and action button; signed-in visitors of a public server get Account, Language & Region, Appearance, Feedback and Release Notes in Settings, resizable columns on desktop, and Join Community in the Help menu.
- improvement: Attachment cards no longer show floating Share and Download icons; tap a file to open it, with Share and Download in the preview.
- improvement: Message rows, the SOS dialog, mention suggestions, the sidebar (reopen closed DMs, drag rows between sections, double-click to open a DM) and task status badges now match the Raft web app (v1.21.12) more closely.

- feature: Videos you have watched are kept on this device, so opening them again starts right away and downloads nothing. Settings › Storage shows how much space the video cache uses and can clear it; signing out removes it.
- feature: Videos of 60 seconds or less play on repeat; longer videos stop at the end.
- feature: Settings › Storage can copy diagnostic information (app version, foreground and background state, and recent storage errors, without messages, credentials or server addresses), and storage error messages have a Copy button.
- fix: Adding a computer no longer stays on the final waiting step after the computer has connected.
- improvement: Updated to the latest Raft design tokens: placeholder and hint text in the elegant theme are slightly darker, and task status icons use the new status colors.

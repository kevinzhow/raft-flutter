- feature: On Linux desktop, the workspace switcher, search, notifications and Back/Forward history now share one row with the window buttons, like on macOS.
- feature: On Windows, notifications now use the system's own toasts and open the right conversation when clicked.
- improvement: Buttons, inputs, banners, progress bars, empty states and cards in the Raft look now follow the web app's current design system.
- improvement: Settings navigation, account and billing pages, and the wording of settings in English and Chinese, now match the web app.
- fix: Settings inputs are no longer pill-shaped, card and popover corners are no longer clipped, and focused inputs no longer show a double border.
- fix: On macOS, the window buttons no longer jump when switching pages.
- fix: Opening an image from a message no longer puts the preview toolbar under the window buttons.
- fix: Chinese button labels on Windows are now vertically centred.
- fix: Scrolling Activity no longer loses its elastic bounce while new items arrive.

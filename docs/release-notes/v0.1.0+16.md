- feature: Sidebar sections and channels can be reordered by dragging; a short press still opens the menu.
- feature: Message history now fills gaps by itself. The "load this part" banner is gone, gaps fill quietly in the background, and an error with a retry button appears only when filling keeps failing.
- feature: Messages kept on the device are protected automatically: conversations opened in the last 7 days, pinned ones, ones with drafts, uploads, unread messages or mentions, and ones open in a window stay available offline. Storage settings now only ask for a size.
- fix: Reply previews under a message ("N replies" and the latest replies) show right away when a conversation opens, when scrolling back, and after a restart.
- fix: Sending or receiving a message no longer triggers extra history requests.
- fix: On desktop, new messages are not marked as read while you are scrolled up reading older ones, and a thread's new-reply count follows reads made on other devices.
- fix: The time shown when hovering a follow-up message stays inside its column instead of overflowing.
- fix: Moving an agent shows each step's progress, can be cancelled and retried, and explains plan limits; Chinese and English wording now matches the web app.
- fix: A failed "Load more" in a channel's files keeps the files already shown, and the feedback inbox keeps "Load more" when a filter hides the loaded tickets.
- fix: On phones, tasks, settings, feedback and saved pages open in place without losing the page underneath.

- feature: With task v2 on, the server Tasks page follows the web: list and board views, the web's sort and filters, column counts, multi-select with bulk status, assignee, follow and delete, and board drag by mouse, touch and keyboard.
- feature: Channels and DMs show Tasks and Files as cards beside the chat on desktop: resize them, stack them, drag them between columns, and the layout is remembered. On phones they cover the chat and Back closes them first.
- feature: Channel details open beside the chat on wide screens, with the channel announcement (it can be an Artifact), members, notification and display settings, visitor visibility and topics sorted by latest activity.
- feature: Account settings: delete your account (with the list of agents, computers and servers it affects, an email code and a waiting period you can cancel), see and revoke apps you signed in to with Raft, search settings, and build a portrait avatar.
- feature: Server administration follows the web section by section, including RaftBench readers and feedback and orphaned joint channels.
- feature: Card buttons can open a web page beside the conversation on iOS, Android and macOS, and a new setting chooses where web links open.
- fix: Tasks opened from the Tasks page, Activity or Search open beside the list under the top bar instead of a floating card, and returning to Tasks shows its rows at once without reloading.
- fix: On desktop, side panels (Details, Tasks, Files, threads) dock beside the chat with one shared frame instead of floating over it; a narrow window folds the thread into the chat first.
- fix: Activity rows for task conversations show their titles again and sort by their latest activity.
- fix: Switching from a task to a message in Activity no longer pops the old task up in the middle of the window.
- fix: Channel Files loads again when a file belongs to a task, and opening a task reply from Files, Search or Saved jumps to the right place.

- feature: Linux AppImage updates itself in the app and downloads only the parts that changed.
- feature: Documents the server cannot preview open from the original file, large files load as you scroll, and any file can be opened with the system app.
- feature: On phones the image viewer is a full-screen black stage with Share and More, and shows who sent the image and when.
- improvement: The image viewer follows a fast swipe, zooms like Web with pinch, double-tap and Ctrl or Cmd with the wheel, and its thumbnail strip scrolls.
- improvement: Search uses each system's shortcuts (Cmd on macOS, Ctrl elsewhere), handles the keyboard like Web and groups results by thread.
- improvement: Cmd+F or Ctrl+F opens find in Activity after you click anywhere in it, like Web.
- improvement: Profile pictures and icons load once and stay cached across restarts; Settings > Storage counts and clears them with the rest of the cache.
- improvement: When a video or audio file cannot play, the app names the real cause (for example an unreachable proxy) and offers the next step.
- improvement: Signing in on the desktop ends on a clear return page and brings the app to the front.
- improvement: @mention suggestions in a thread include the members of the thread's channel.
- fix: Android no longer crashes when the app goes to the background while a video is playing.
- fix: Message headers no longer cut off the bottom of letters such as g, y and p or of Chinese characters.
- fix: On phones, selected text clears when you tap elsewhere, and Android no longer leaves a focus ring around the app after a key press.

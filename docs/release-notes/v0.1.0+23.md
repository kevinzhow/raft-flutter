- feature: Change the model of several Agents at once from a computer's page: pick the Agents, review the change, then apply it. Each Agent keeps its own environment and settings, and anything that could not be saved can be retried on its own.
- feature: On Mac, iPhone, iPad and Android, a banner above the message box offers to turn on notifications, like on Web. The system asks for permission only when you tap Enable notifications; if notifications are off in system settings, Settings › Notifications says so and opens the system page.
- improvement: An Agent's profile shows its Skills collapsed by default, with the arrow at the end of the header so section titles line up; tapping the avatar in a direct message opens that person's profile, also from the keyboard.
- improvement: Empty sidebar sections are shown by default again. If you had chosen to hide them, that choice is kept.
- fix: Text in buttons, labels, badges, input fields and other controls no longer sits low or gets cut off with Chinese text on Android or with larger system text.
- fix: Spacing across the app follows the same grid as Web, so a few chips and gaps line up again.

- feature: Activity has a Direct Messages view that shows only private conversations, on phones and desktop, with its own unread count.
- feature: Settings has an MCP tab like the web app: add or edit a server in one editor, set several headers, test the connection with what you are editing, and keep saved secrets unchanged unless you replace them.
- feature: The Mac app menu and the Windows title bar and tray menus have Check for Updates, also before you sign in.
- improvement: Pending mentions in Activity have the same menu as other rows. Done removes only that mention, and marking read or unread updates the list right away.
- improvement: You can read a new version's release notes before updating, and the notes page refreshes and marks the version you have installed.
- improvement: The desktop workspace grid (several channels side by side) was removed, as on the web app.
- fix: Scrolling messages and lists on a touch screen no longer shows the hover borders meant for a mouse.
- fix: The sidebar no longer changes width when you open Activity.
- fix: Text from voice input on the Mac (for example a dictation app started with Fn+B) now lands in the message box, and a paste keeps your text when another app puts the clipboard back.
- fix: Messages that arrive late over the live connection are no longer dropped.
- fix: Creating an agent counts seats the same way as the plans page, so a workspace below its limit is no longer told it is full.
- fix: A finger drag on a bottom sheet's handle moves the sheet even when its content is scrolled.
- fix: Restoring all agents reports each one that failed, and a partial failure is no longer shown as success.
- fix: The agent profile editor stays open when the window is resized across the phone and desktop widths.

# 布局、显示语言与组件验收

参照：`raft-source` 26f77ef97c40d3d91aa2c5e42b0fd66b8bf39fe6，Web `panelBounds.ts`、`LeftRail.tsx`、`auth.ts` 显示语言合同。

## 窗口与输入

- `RaftAdaptiveWorkspace` 用实际父约束布局：小于 900 px 显示单面板与移动导航；900 px 起显示 64 px 导航轨与频道侧栏；1100 px 起线程显示为右侧面板。900–1099 px 的线程使用主内容位置，保证可读宽度。
- 侧栏宽度 180–320 px，默认 240 px。线程默认 400 px、最小 360 px；最大值同时受窗口 60% 和主内容至少 320 px 的限制。窗口缩小后不产生负宽度或隐藏正文。
- 分隔条支持鼠标/触摸拖动、键盘方向键和无障碍增减动作。快速连续指针更新使用累加值，避免一个渲染帧内丢失拖动位移。宽度偏好保存在本地，不含用户内容。
- 桌面 `Ctrl/Cmd+K` 打开搜索，`Ctrl/Cmd+,` 打开设置，`Escape` 关闭抽屉或线程/返回聊天。移动返回键先关闭当前线程或返回聊天。切到搜索、设置等区域后，保留的线程状态不会覆盖该区域。

## 显示语言

- 后端 `displayLanguage` 为 `en`、`zh-cn` 或 `null`，与消息翻译偏好 `preferredLanguage` 分离。
- 账户设置的显示语言表单真实 PATCH `/auth/me` 并重新读取账户；主应用使用对应 Flutter `Locale` 和官方 Material/Widgets/Cupertino 本地化委托。
- 跟随设备只解析已提供的 UI 语言；简体中文设备解析到 `zh-CN`，其他未提供的语言回退到英语。
- 固定 UI 文字来自参照 Web 英文/中文目录及原生新增控件翻译。按钮、表单、导航、账户、频道、成员、任务与设备管理使用该目录。
- 模板先翻译固定文字，再一次性插入用户名称等参数。用户消息、频道/工作空间名称、文件名、模型标识和协议值不按偶然匹配的英文词翻译。用户参数中的 `{role}` 等文本不会被二次替换。
- 服务端返回的未识别错误与没有中文目录项的运行时说明保留原文；这部分不宣称完成中文翻译。

## 登录入口与资料

主应用接入 `AuthView` 的登录、注册、密码恢复和原生 OAuth 入口。恢复的会话同样先经过邮箱验证与永久用户名设置，满足条件后才请求工作空间。语言更新、前后台读取保护、当前账户缓存隔离保留原有处理。

账户头像接入真实原生文件选择及头像 API。移除头像需要明确确认，上传/移除过程显示忙碌与错误。头像上传、注册与外部 OAuth 的实际平台证明由对应流程报告记录，不能以本页的布局测试代替。

## 自定义侧栏与分享入口

侧栏显示后端的 `sectionOrder`、`customSections`、`sectionPlacements`、频道/DM 手动顺序、隐藏 DM 和各区域排序模式。固定/自定义分组中的会话从默认区域去重；联合频道单独显示。Agent 条目解析真实目录和既有 DM，打开时使用真实 DM 创建协议，不把 Agent 名称当作用户身份。用户提供的分组名称与 emoji 保留原文。

最近活动排序只使用后端 `lastMessageAt` 或当前工作空间实际消息的 `createdAt`；没有活动数据的条目保留原来的手动顺序，不用本地时间或资源创建时间伪造活动。4 个投影测试通过。

消息操作菜单新增 Android 系统分享链接和各原生平台复制链接入口，调用平台功能前重新验证消息上下文。传入分享只在当前已加入会话准备好后注册接收，先显示用户确认，不自动发送；平台解析、私有文件导出及授权细节以独立平台报告为准。

主应用同时对分别构造的登录客户端做尝试序号检查和串行持久化检查。退出立即解除当前 UI，清空任务排队在后续登录写入之前；3 个测试验证旧登录响应、已经开始的存储写入和重新登录之间的最终持久化顺序。

## 桌面工作空间窗口边界

Linux 工作空间菜单在明确配置 `RAFT_FRONTEND_ORIGIN` 并绑定当前 `RAFT_ORIGIN` 时，提供浏览器入口与鼠标中键操作。它先重新读取成员工作空间，再打开公开页面，不把登录凭据传递给浏览器。没有配置时隐藏该入口，不猜测 API 地址是否托管 Web。独立原生多窗口仍未实现；参照来源、测试和浏览器生命周期边界记录于 `desktop-window-evidence.md`。

HTML 原生静态预览、明确浏览器交互入口和三主题 SDK 证据记录于 `html-preview-evidence.md`。静态 HTML 不执行上传脚本，不加载其图片引用。
